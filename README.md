# ❤️ BAZHDAR & SHAZIN ❤️ — Love Forever

Ultra Luxury Romantic Love Website with 3D effects, particle systems, and interactive animations.

## Features

- Full-screen cinematic landing page
- Animated crystal heart centerpiece
- Thousands of floating hearts & sparkles
- Three.js 3D ambient hearts
- GSAP scroll animations
- Polaroid memory gallery
- Love timeline & letters
- Future dreams section
- Heart fireworks & click interactions
- Rose petals & golden particles
- Background ambient music (Web Audio)
- PWA ready · Mobile-first · RTL Kurdish

## Run locally

```bash
# Any static server, e.g.
npx serve .
# or
python3 -m http.server 8080
```

Open `http://localhost:8080`

## Stack

- HTML5 · CSS3 · JavaScript
- Three.js · GSAP
- Canvas particle engines
